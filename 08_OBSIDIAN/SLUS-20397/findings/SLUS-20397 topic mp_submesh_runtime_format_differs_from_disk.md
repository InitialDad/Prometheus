# mp_submesh_runtime_format_differs_from_disk

Game: [[SLUS-20397 Tenchu Wrath of Heaven]]

- **2026-06-16 works** — Submeshes in live RAM have NO KMDp/KMDs magic. The CHARA.BIN stores submeshes with proper headers but the runtime loader transforms them into VIF-DMA-ready blocks that strip the magic. To inspect submesh structure, must read the on-disk CHARA.BIN copy (chara_bin_tool.py), not the live RAM. Confirmed for MP Char F: 22 KMDp + 3 KMDs + 3 other on disk; 0+0+28 on live.
