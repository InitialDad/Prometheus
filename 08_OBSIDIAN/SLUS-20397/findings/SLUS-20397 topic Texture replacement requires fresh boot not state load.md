# Texture replacement requires fresh boot (not state load)

Game: [[SLUS-20397 Tenchu Wrath of Heaven]]

- **2026-06-15 works** — PCSX2's GPU texture cache loads replacement textures from disk ONLY on first upload after a fresh boot. Loading a save state uses the GPU state cached IN the save file, bypassing disk replacement. To test new texture replacements: kill PCSX2 → relaunch with ISO (no -state flag) → boot to title → load save state from menu. This forces fresh texture uploads.
